# @trade-monitor/terminal-ui

Canonical, screen-independent terminal presentation/interaction source, version 0.1.0 / UI contract 1. Bundled ESM, CSS, licensed fonts and chart vendor. No business API, account state, numbered registry, strategy code or execution policy.

Consumers pin a full public Git commit through the included installer and keep the generated bytes local. No runtime CDN or npm publication is required. See [the integration contract](../../docs/SHARED_UI.md) for typography tokens, JS APIs, versioned updates and ownership.

Edit src/, regenerate the deterministic manifest, sync the public preview, test, then update each consumer's lock. Do not modify a vendored shared copy. LICENSE/NOTICE/provenance of bundled dependencies are in licenses/. IBM Plex Mono is not Bloomberg's proprietary font.
