# Code-first screen review — all numbered functions

The single broker connection is server-owned. No account ID, credentials or account picker is required for normal use. Each strategy retains a stable code key for its owned orders/PnL; this is not another brokerage account. Source code/drafts remain private, memory-only in the browser and protected on the engine. Public Pages never receives or publishes them.

## Use

- 0304 CODE: historical Python + risk/execution TOML; research dates/selection conditions are one JSON request, resolved against the saved default universe. CHECK/review and historical results do not activate trading.
- 0504 OPERATE/BROKER: one Python declaration document for ACCOUNT and STRATEGIES, including each strategy's source/manifest/capital. Loaded from the actual connected account, not invented defaults. CHECK is inert. APPLY REVIEWED CODE requires the exact document/engine/policy; it does not start. START/PAUSE/STOP act on the applied version; unapplied edits block START. FLATTEN appears only for observed holdings.
- Schedule is ACCOUNT.schedule in the same document: KST weekdays, prepare/start/pause times, explicit session budget. Server supervision owns it, not a manually installed date timer. Provider session/freshness/account/risk still govern actual orders. A manual same-day STOP/PAUSE wins; restart never resets a strategy checkpoint.
- 0412 UNIV: one JSON rule; PREVIEW shows actual resolved members, SAVE replaces the default future-research rule with revision CAS. UPDATE MASTER requests official reference refresh. No manual ID/default/name/market form duplication.
- 0411 DATAFLOW: requests and recording policies first. Reviewed recording uses one JSON declaration (including exact completed research ID and generation); it is not order approval. Only eligible non-synthetic research is listed. Stop actions carry the observed generation. Pagination appears only when needed.
- 0410 STATS: actual registered tool plus one JSON parameter block; unsupported fields are rejected. A historical result/paired peer is required when applicable.
- 0602 DATABASE: read-only schema/capacity evidence and one JSON retention policy. SAVE REVIEWED POLICY carries generation CAS. Engine archives oldest eligible records, verifies exact envelopes/checksums, then removes the hot copy. News/disclosures are protected. A full local archive/disk blocks deletion. A five-minute bounded worker handles the policy; no paid upgrade is implied.

No typography/color/chart package rewrite. Market controls, modal close, security rotation and immutable research evidence are intentionally preserved. This audit does not claim every input is removable or every operating strategy/cadence is supported. Unsupported contracts fail before activation.
