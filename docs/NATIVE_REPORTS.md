# 엔진 원본 결과 읽기

비공개 엔진의 기존 응답이 기준 계약이다. 실행/백테스트·데이터 관리·계좌 장부/리스크/주문 정책을 공개 앱에서 다시 구현하지 않는다.

워크스페이스 → 결과 파일 열기에서 아래 JSON을 현재 탭에 읽는다.

- 단일 실행: `id`, `summary`, `curve`, `orders`, `fills`와 선택적 `market`, `decisions`, `limits`, `plugin` 등.
- 계좌: `id`, `status`, `mode`, `as_of`, `updated_at`, `summary`, `curve`, `strategies`와 선택적 `runs` (실행 ID별 자식 결과).

기존 GET `/api/runs/{id}` 및 GET `/api/accounts/{id}` 응답을 변환하지 않고 소비하는 경로다. 엔진의 원래 파일 export에 자식 runs가 없다면 계좌 장부만 표시하고 전략별 상세/시세는 미포함으로 표시한다. API 서버에 자동 접속하는 기능은 이번 구현에 포함하지 않는다.

## 전략 중심 조회

여러 원본 파일을 현재 탭에 열어 포트폴리오를 전환할 수 있다. 현재 엔진의 계좌 실행이 포트폴리오 단위이며 새 엔진 계층을 요구하지 않는다. 전략 선택은 성과·보유·리스크·체결과 기여도 선택에 연동된다. 상세 원천이 없는 계좌 전략 행은 미보고로 표시한다. 마켓의 공개/실행 저장 봉은 별도 출처 선택이며 결과 파일을 열었다는 이유로 공개 시장 데이터와 섞지 않는다. [분석 정책](STRATEGY_MONITORING.md).

## 보존하는 의미

- `summary`, `curve[].timestamp`, 엔진 상태 문자열을 유지한다. `completed_with_errors`를 일반 완료로 바꾸지 않는다.
- DSL 등에서 코드 해시가 없으면 미보고로 표시한다. `snapshot_id`, `sequence`, 임의 코드/데이터 해시를 생성하지 않는다. 이전 관측 v1 파일은 별도 호환 경로다.
- 계좌 NAV/손익/기여도/대사 잔차는 엔진 보고 값이다. 독립 전략을 다시 합산하지 않는다. 내부 장부 대사와 증권사 대사를 구분한다.
- 자식 결과가 포함돼 있으면 계좌 ID·전략 ID·실행 ID와 마지막 평가 시각이 계좌와 일치해야 한다. 불일치는 import 전에 거부한다.
- 실행을 선택하면 가격/종목 목록은 그 결과의 market 봉을 사용한다. 공개 스냅샷을 대신 붙이지 않는다. 봉이 없으면 비어 있다. 원천/조정/상품 가격 단위를 알 수 없는 저장 봉에는 그 한계를 표시한다.
- 모든 텍스트를 escape해서 표시하고 코드/문자열을 실행하지 않는다. 파일 크기 상한 5MiB, 필수 필드/시간대/유한 숫자/curve 순서/market OHLCV를 검사한다. 모르는 확장 필드는 보존하며 화면에서 임의 해석하지 않는다.

## 저장과 배포

파일·계좌/실행 ID·결과·파일 속 종목은 탭 메모리에만 있다. 브라우저 새로고침/파일 닫기로 해제한다. 창 종류/배치 좌표·크기만 localStorage에 저장한다. Pages 산출물은 여전히 빈 runtime-state를 사용하며 개인 엔진 데이터를 읽어 export하지 않는다. 합성 계약 테스트는 tests/native-fixtures.mjs, 소비기는 web/native-report.js다.

직접 HTTP 연동은 비공개 실행 환경에서 기존 읽기 API와 인증/동일 출처 구성을 연결하는 후속 단계다. 공개 대시보드의 배포 코드에 운영 응답/키를 포함하거나 비공개 저장소에 푸시하지 않는다.
