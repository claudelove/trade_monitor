# 저장소별 담당과 작업 인계

2026-11-04 사용자 결정: 비공개 저장소에서 데이터 관리·전략 관련 업무를 진행하고, 모니터링 대시보드는 이 공개 저장소에서 이어간다. **이 작업의 커밋·푸시 대상은 claudelove/trade_monitor의 work 브랜치뿐이다. 비공개 저장소에 푸시하지 않는다.**

## 담당 범위

| 영역 | 담당 저장소 | 대시보드가 사용하는 것 |
| --- | --- | --- |
| 데이터 수집·정정·품질·원천 저장 | 비공개 krx_hedgefund | 조회용 데이터와 출처·시점·품질 |
| 전략 코드·검토·실행·백테스트 | 비공개 krx_hedgefund | 코드 식별 정보와 실행 결과 |
| 계좌 장부·리스크 정책·주문·체결 | 비공개 krx_hedgefund | 보고된 계좌/전략 상태·장부·리스크·주문·체결 |
| 화면·차트·검색·워크스페이스 | 공개 trade_monitor | 화면 코드와 공개 가능한 합성 검증 사례 |
| 읽기 전용 조회 어댑터·화면 계약 | 공개 trade_monitor | 비공개 환경에서 실행할 수 있는 연동 코드 |

비공개 저장소의 커밋된 문서와 모니터링 API 구현을 읽어 작업을 이어간다. 다른 컴퓨터의 채팅·미커밋 파일·운영 DB에는 자동 접근하지 않는다. 비공개 저장소에 쓰기 작업이 필요하면 필요한 API 변경 내용을 이쪽 인계 문서에 정리하며 직접 커밋/푸시하지 않는다.

비공개 전략 구현·설정·원천 데이터·계좌 결과를 공개 저장소로 옮기지 않는다. 공개하는 것은 UI/조회 연동 코드와 합성 테스트 입력이다. 현재 저장소의 시장 수집 코드는 기존 공개 미리보기용으로 보존돼 있지만 비공개 데이터 플랫폼의 새 구현을 이곳에 복제하지 않는다.

## 확인한 연동 출발점

비공개 서버에는 아래 읽기 경로가 구현돼 있다. 이 경로의 존재를 확인했으며 실행 중인 서버나 개인 DB에 연결했다는 뜻은 아니다.

| 비공개 조회 경로 | 화면에서 사용할 범위 | 현재 공개 앱과 차이 |
| --- | --- | --- |
| GET /api/accounts | 계좌 실행 선택 | 공개 앱은 계좌 목록 계약 미구현 |
| GET /api/accounts/{id} | 계좌 장부와 같은 publication의 전략 결과 | ACCOUNT는 현재 미연결; 계좌 데이터 계약 필요 |
| GET /api/runs 및 /api/runs/{id} | 개별 실행·시장 봉·지표·주문·체결 | 현재 /api/runtime 형식과 직접 호환되지 않음 |
| GET /api/data/events 및 /api/data/events/{id} | 원천/정정·가용/수신 시각·품질 | 현재 공시/뉴스 스냅샷과 별도 데이터 계약 |

비공개 엔진은 기존 실행 규칙을 유지한다. 대시보드는 그 결과를 읽으며 엔진을 import해 실행하거나 정책을 재계산하지 않는다. 현재 관측 v1의 해시/sequence 등 필수 값이 원천 결과에 없으면 확인된 값으로 명시적 매핑하거나 별도 버전 계약을 사용한다. 누락된 정보를 가짜 값으로 채워 검증을 통과시키지 않는다.

## 다음 구현의 기준

1. 읽기 전용 어댑터와 합성 계약 테스트를 공개 저장소에서 구현한다. 실제 비공개 데이터는 테스트 fixture/Pages 산출물로 만들지 않는다.
2. 계좌 context와 전략 context를 구분한다. 계좌 응답의 장부/기여도를 표시하고 독립 전략 결과를 임의 합산하지 않는다. 계좌와 자식 결과는 같은 publication 기준으로 표시한다.
3. 과거 재생/모의/실거래, 시장 시점/수신 시점, 내부 장부 대사/증권사 대사를 구분한다. API 오류·오래된 running 상태를 최신 정상 상태로 표시하지 않는다.
4. 원천/시장 차트는 실제 보고된 봉을 사용한다. 서로 다른 데이터셋의 공시/시세/전략 결과를 같은 실행의 자료로 보이게 합치지 않는다.
5. 프런트엔드 코드는 공개할 수 있지만 비공개 API 응답과 자격 증명은 공개 배포에 포함하지 않는다. 실제 조회 연결은 비공개 backend/동일 출처 또는 명시적으로 인증된 환경에서 제공한다.

현재 GitHub Pages는 공개 시장 스냅샷과 탭 메모리의 결과 파일 조회만 지원한다. 자동 실시간 연결·계좌 API 어댑터·비공개 엔진 제어는 아직 구현하지 않았다. UI 코드 저장 위치와 운영 데이터 제공 위치는 별개다. 새 클라우드 리소스·공급자 작업·주문을 이 분리 작업만으로 생성/실행하지 않는다.
