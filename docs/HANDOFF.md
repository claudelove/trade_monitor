## 사용자의 목표/운영 원칙

- 저장소: https://github.com/claudelove/trade_monitor
- 개발·자동 배포 브랜치: `work`. main에는 초기 커밋만 있고 자동 병합하지 않는다.

- 실제 앱 HTTPS URL: 미발급. localhost/배포 설정 링크를 가동 중인 앱 주소로 안내하지 않는다.
- 사용자 다음 행동: docs/DEPLOYMENT.md의 Render 링크에서 계정 연결·비용 확인·최초 서비스 생성. DART 키는 Codex가 아닌 Render 환경 변수에 입력.

## 구현 완료

- FastAPI·SQLite·정적 ES 모듈 UI. 위젯 순서/표시, 검색·필터·관심 목록·CSV.
- DART 5개 이벤트 전략 분류·원문, 전후 차트, 이벤트 이후 1/3/5/10/20일 가격·벤치마크 초과수익.
- RSS 기본/기업·기간 검색. 공개매수 수동 시나리오 계산.
- 롱온리 단일 포지션 이벤트 백테스트: 다음 거래일 시가, 편도 비용, 정정/중복/불충분 데이터 제외, 일봉 MDD.
- 공급자 실패 격리·누적 중복 제거·이전 캐시 시각 유지. pykrx 80초 프로세스 제한.
- pykrx 수정주가는 NAVER 경로임을 명시. KRX 직접 인증 성공은 아님.
- 배포용 PORT 처리, 비밀번호 필수 모드, 공개 최소 healthz, 영속 디스크 권한 초기화 후 비루트 실행.
- 공개 데이터 기준 스냅샷 export/빈 DB restore. 운영 데이터가 있으면 덮어쓰지 않음.
- GitHub Actions Python/JS/UI DOM 검사 정의.

## 데이터와 비밀

- fixtures/bootstrap-live.json: 공개 데이터 공시 502건, 뉴스 74건, 12종목 264개 일봉. 공시 56건 가격 연결. 기준 2026-11-03.
- 현재 클라우드 DB: data/monitor.db. Git 제외이며 다른 환경에 자동 전달되지 않는다.
- 새 Docker 배포는 빈 DB에서 Git 스냅샷 자동 복구. 이후 데이터는 Render /var/data/monitor.db에 보존.
- Git 스냅샷은 과거 기준 자료다. 매 수집 후 자동 백업되는 것이 아니다. 자동 외부 DB 백업은 미구성.
- DART_API_KEY는 런타임에서만 사용. 다른 채팅/환경의 설정 여부는 별도 확인. Render 비밀번호도 Git에 넣지 않는다.
- 관심 목록과 위젯 구성은 브라우저 localStorage에 저장된다. 다른 브라우저/기기에는 동기화되지 않는다.
